# 🎹 GlassKey Studio — Interactive Web Piano & Song Search Engine

GlassKey Studio ek modern, lightweight aur visual web piano hai jo pure **HTML5, CSS3, aur JavaScript (Web Audio API)** se bana hai. Isme aap manual piano play kar sakte hain, custom sound mode enable kar sakte hain, aur Bollywood, Bhojpuri, Tollywood, aur Hollywood songs search karke auto-play kar sakte hain.

---

## ✨ Features

* **🎨 Glassmorphic UI & Dynamic Themes:** Translucent glass effect ke sath Neon Indigo, Sunset Pink, Emerald Forest, aur Cyber Gold themes.
* **🎵 Web Audio API Synthesizer:** Bina kisi external audio/MP3 file ke direct browser me sound generate karta hai (Sine, Triangle, Sawtooth, Square waveforms).
* **♾️ Continuous Sound Mode:** Sound toggle feature jisse key ka note tab tak bajta rehta hai jab tak aap use manually stop na karein.
* **🔍 Multi-Language Song Search:** Bollywood, Bhojpuri, Tollywood, aur Hollywood songs ko search karke unki melody auto-play karne ka option.
* **🎹 Physical Keyboard Support:** Desktop keyboard (A-N keys) se piano notes bajane ki suvidha.
* **📁 MIDI File Upload:** External `.mid` / `.midi` files ko import karke custom songs bajane ka option.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox & CSS Grid, Backdrop Filters)
* **Logic & Audio Engine:** Vanilla JavaScript, Web Audio API
* **Graphics:** HTML5 Canvas (Particle Effects)
